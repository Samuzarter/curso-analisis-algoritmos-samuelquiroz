# Curso de Análisis de Algoritmos

Repositorio de trabajo para el semestre: laboratorios evaluativos, ejercicios
de clase y benchmarks de rendimiento.

## Estructura del repositorio

- `laboratorios/`: contendrá una carpeta por cada uno de los cinco informes
  de laboratorio evaluativos del semestre.
- `ejercicios-clase/`: código de las sesiones prácticas no evaluativas,
  incluyendo los ejercicios de Python de la Semana 2.
- `benchmarks/`: scripts compartidos para medir tiempos de ejecución y
  graficar resultados, reutilizados en los laboratorios evaluativos.

## Cómo clonar este repositorio

```bash
git clone https://github.com/Samuzarter/curso-analisis-algoritmos-samuelquiroz.git
cd curso-analisis-algoritmos-samuelquiroz
```
